# Ajinkya Ghodke - Portfolio

Personal portfolio website for Ajinkya Ghodke, SDET / QA Automation Engineer (Banking & FinTech).

## Sections

Home · About · Projects · Skills · Resume · Contact

## Tech

Plain HTML, CSS and JavaScript. No build step or dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

The site is static and can be hosted with GitHub Pages (Settings > Pages > deploy from the `master` branch, root folder).

```
index.html
```
